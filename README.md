## 简介

[`CondorAdmin-webman`](https://gitee.com/wbcondor/condor-webman) 是一款基于 PHP 与 webman 框架开发的后台管理系统后端。webman 框架构建于 Workerman 之上，是一款常驻内存的高性能服务框架。CondorAdmin 提供一站式后台管理解决方案，开箱即用，无需额外配置，同时也是快速学习和实践前沿技术的优秀示例。

## 特性

- **后端技术：** PHP，Webman，Mysql，Redis，JWT

## 使用

**环境准备**

确保你的环境满足以下要求：

- **git**: 你需要git来克隆和管理项目版本。
- **PHP**: >=8.0.0。
- **MySql**: >= 8.0.0。

**克隆项目**

```bash
# gitee
git clone https://gitee.com/wbcondor/condor-webman.git
```

**安装依赖**

```bash
conposer install
```

**启动项目**

```bash
# windows用户请执行
php windows.php
# 非window用户请执行
php start.php start
```

**代码同步**

参考 [代码同步](https://docs.soybeanjs.cn/zh/guide/sync) 文档。
